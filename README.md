## Описание проекта

Репозиторий создан как fork учебного репозитория
[BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC) и используется для выполнения
лабораторных работ по дисциплине. В нём последовательно выполняются все этапы
жизненного цикла программного продукта:

1. анализ и спецификация требований (SRS) — по шаблонам из папки `srs/`;
2. проектирование архитектуры (SDD) и фиксация архитектурных решений (ADR) — по
   шаблонам из папок `sdd/` и `adr/`;
3. разработка программного обеспечения — в папке `project/`;
4. тестирование, сборка и сопровождение.

Проект в папке `project/` — пустой шаблон настольного приложения Windows Forms
на языке C# (.NET 10), в котором в дальнейшем будет выполняться проектирование
и разработка задания. Среда разработки — Microsoft Visual Studio Community 2026.

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `project/SdlcProject.slnx` | Файл решения Visual Studio |
| `project/SdlcProject/` | Проект приложения (C#, .NET 10, Windows Forms) |
| `srs/`, `sdd/`, `adr/` | Шаблоны проектной документации (SRS, SDD, ADR) |
| `docs/` | Справочные материалы по стандартам и терминологии |
| `.gitignore` | Список временных файлов и папок, не попадающих в репозиторий |

| Ветка | Содержимое |

## Сборка и запуск

Требуется .NET SDK 10 (или Visual Studio 2026 с рабочей нагрузкой
«Разработка классических приложений .NET»).

```bash
cd project
dotnet build
dotnet run --project SdlcProject
```
